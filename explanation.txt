Домашнє завдання 5 — коротке пояснення

1. SELECT od.* виводить усі поля order_details. Внутрішній SELECT знаходить customer_id у orders; WHERE o.id = od.order_id пов'язує його з поточним рядком. AS customer_id задає назву нового стовпця.

2. Внутрішній SELECT обирає номери замовлень із shipper_id = 3. Умова IN залишає тільки відповідні рядки order_details.

3. Вкладений запит FROM спочатку залишає quantity > 10. Зовнішній SELECT обчислює AVG(quantity), а GROUP BY order_id формує окреме середнє для кожного замовлення.

4. WITH temp AS надає відфільтрованій вибірці ім'я temp у межах одного запиту. Подальші AVG і GROUP BY повторюють пункт 3; результати мають збігатися.

5. DROP FUNCTION IF EXISTS дозволяє повторно створити функцію. Обидва параметри й результат мають тип FLOAT. DETERMINISTIC означає однаковий результат для однакових аргументів; NO SQL — відсутність операцій із таблицями у тілі функції. RETURN повертає частку; NULLIF замінює нульовий знаменник на NULL. Виклик hw05_divide_float(quantity, 2.0) ділить кількість на 2.

ORDER BY впорядковує результати для зручної перевірки. USE mydb обирає базу даних.
